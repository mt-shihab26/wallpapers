# wallpapers

My wallpapers collections

## Omarchy

Symlink these wallpapers into the backgrounds folder of your currently active
Omarchy theme:

```sh
./link.sh
```

This detects the active theme with `omarchy-theme-current` and links every
image here into `~/.config/omarchy/backgrounds/<theme>/`. Re-run it any time
you add a new wallpaper or switch themes. Cycle through the linked wallpapers
with:

```sh
omarchy-theme-bg-next
```
